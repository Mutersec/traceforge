# Code of conduct

## Our pledge

We want participation in TraceForge to be a harassment-free experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and assume good faith.
- Give technical feedback about the code, evidence, or behavior, not the person.
- Do not publish private data, credentials, or third-party target material.
- Do not use project spaces to request help with unauthorized access, malware
  deployment, license circumvention, or evasion.

## Unacceptable behavior

Harassment, discriminatory language, credible threats, doxxing, unwanted sexual
attention, and deliberate disruption are not tolerated.

## Enforcement

Maintainers may remove comments, close discussions, or block accounts when
behavior violates this code. Report concerns privately through the repository's
security advisory channel when public discussion would expose sensitive data.

This code is adapted from the spirit of the Contributor Covenant, version 2.1.
